## Общие правила

Не менять бизнес-правила и контракты ради удобства теста. Пробел проверки не считать доказанным дефектом реализации. Если тест выявит дефект по однозначному требованию, исправить его в границах своего компонента и добавить воспроизводящую проверку. При неоднозначности спросить пользователя до реализации. PostgreSQL — только новые Docker-контейнеры с явными DSN, без reuse и fallback. При недоступности Docker остановить проверки с БД. Отчёт должен содержать команду, среду, фактический результат и оставшиеся ограничения; не заменять историю старых прогонов новыми числами.
